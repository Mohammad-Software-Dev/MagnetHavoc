# Characters and Cosmetics

## Character strategy

At launch, characters are primarily **cosmetic identities**, not radically different combat classes. This reduces animation scope, balance complexity, matchmaking fairness issues, and pay-to-win risk.

The world calls the competitors **Mags**: compact robotic or armored beings built around a magnetic Flux Core chassis.

## Base gameplay body

All ranked-compatible Mags share:
- Same collision capsule.
- Same base movement speed.
- Same mass class.
- Same default Push/Pull strength.
- Same dash behavior.

Cosmetics may alter silhouette within strict readability bounds but cannot alter hitboxes.

## Cosmetic slots

Recommended slots:
- Body shell / skin.
- Face/visor expression set.
- Head accessory.
- Magnet VFX trail.
- Push burst effect.
- Pull field effect.
- Knockout effect.
- Victory animation.
- Emote wheel.
- Player banner / profile plate.
- Footstep / hover trail.

Do not launch with every slot. Prioritize body skin, emote, victory animation, and magnetic VFX first.

## Visual archetypes

Potential cosmetic families:
- Factory Bot.
- Junkyard Punk.
- Space Knight.
- Retro Arcade Machine.
- Deep-Sea Diver.
- Toy Dinosaur Mech.
- Street Racer.
- Wizard-Tech parody.
- Construction Bot.
- Neon Idol.

The tone should support playful absurdity without requiring lore explanations.

## Animation requirements

Base rig should support:
- Idle.
- Run forward/side/back blend.
- Fast turn / lean.
- Dash anticipation and burst.
- Pull pose/channel.
- Push recoil pose.
- Light hit.
- Heavy stagger.
- Tumble/ragdoll blend.
- Recovery/get-up.
- Edge teeter if used.
- Core possession locomotion variant.
- Victory/defeat.
- Emotes.

## Ragdoll strategy

Use controlled ragdoll or animation-to-ragdoll blending only for strong impacts. Pure uncontrolled ragdoll during ordinary play can feel unresponsive and create network divergence. The authoritative gameplay representation should remain simple even if the visual rig exaggerates impacts locally.

## Readability rules

- Local player has a subtle always-visible identifier.
- Rival nameplates are compact and can fade at distance.
- Team modes use strong team rings/accents independent of skin color.
- Cosmetics cannot mimic the Flux Core or hazard warning colors.
- Large accessories must not hide body orientation.

## Future sidegrade abilities

If the game later introduces selectable gadgets, they should be separate from cosmetic character identity. A skin should never imply gameplay power. This lets players choose their look independently from their tactical loadout.

## Content production target

A healthy season can add:
- 3–5 skins at varied rarity.
- 2–4 emotes.
- 1–2 victory animations.
- 2–3 magnet VFX variants.
- Banner/profile cosmetics.

These are targets, not launch requirements.
